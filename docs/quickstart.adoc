= 快速开始
:toc: left
:toclevels: 2
:icons: font
:sectlinks:

本指南介绍从获取源码到烧录固件的完整流程。

== 环境准备

=== 获取源码

[source,bash]
----
git clone git@github.com:lzx3in/CubeMot.git
cd CubeMot
----

=== 安装依赖

[source,bash]
----
python3 -m venv .venv
source .venv/bin/activate
pip install -r tools/requirements.txt
----

== 配置与构建

项目使用 **CMake Presets** 管理构建配置。

=== 配置系统参数（可选）

板型和其他参数通过 Kconfig 选择：

[source,bash]
----
menuconfig Kconfig
----

若不手动配置，构建系统将使用默认配置。

NOTE: 详细配置说明，请参阅 xref:kconfig.adoc[KConfig 配置系统]。

=== 快速构建

使用 Workflow Presets 一键完成配置+构建：

[source,bash]
----
# 固件构建
cmake --workflow --preset embedded-debug

# 清理+构建
cmake --workflow --preset embedded-debug-clean
----

NOTE: 详细构建说明，请参阅 link:BUILDING.adoc[构建指导文档]。

== 运行单元测试

[source,bash]
----
# 一键完成（推荐）
cmake --workflow --preset test-debug

# 或分步执行
cmake --preset test-debug
cmake --build --preset test-debug
ctest --preset test-debug
----

NOTE: 完整测试说明，请参阅 xref:unit_testing.adoc[单元测试文档]。

== 烧录固件

[source,bash]
----
openocd -f target/nucleo_g431rb/Debug/openocd.cfg \
  -c "program target/nucleo_g431rb/Debug/CubeMot.elf verify reset exit"
----

== 调试

=== 启动 OpenOCD 调试服务器

保持此终端运行：

[source,bash]
----
openocd -f target/nucleo_g431rb/Debug/openocd.cfg
----

=== 连接 GDB

在另一个终端中：

[source,bash]
----
gdb-multiarch target/nucleo_g431rb/Debug/CubeMot.elf

# 在 GDB 中连接 OpenOCD
(gdb) target remote localhost:3333

# 加载程序（若尚未烧录）
(gdb) load

# 重置并暂停在入口点
(gdb) monitor reset halt

# 设置断点（示例）
(gdb) break main

# 继续执行
(gdb) continue
----

=== 常用 GDB 命令

[cols="1,2"]
|===
| 命令 | 说明

| `continue` 或 `c` | 继续执行
| `step` 或 `s` | 单步进入
| `next` 或 `n` | 单步跳过
| `finish` | 运行到当前函数返回
| `break <location>` | 设置断点
| `info breakpoints` | 查看断点列表
| `delete <num>` | 删除断点
| `print <var>` | 打印变量值
| `backtrace` 或 `bt` | 查看调用栈
| `info registers` | 查看寄存器
| `x/<n><f><u> <addr>` | 检查内存
| `monitor reset halt` | 复位并暂停目标
| `detach` | 断开连接
| `quit` | 退出 GDB
|===
